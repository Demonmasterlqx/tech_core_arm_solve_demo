本轮覆盖 `planning.cpp`、`planning_scene.cpp`、`planning_ik.cpp`、CLI与汇总脚本。抓取检查现已改为固定几何区域证书，指定装配端面采用支持面分离证书。首个完整基线探针已通过独立URDF审计；以下结论仍不替代全部冻结任务的结果或真实机械臂验收，没有用旧场景失败记录推导新版性能。

## 基线与三级规划

正常参数下 baseline 保留固定上游 `6edc630a1a14a3904b42d5a360e9020562eefc99` 的 `[Jv;(I-aaᵀ)Jω]`、λ=1e-4及λ²正则、六行LDLT、alpha=.2、300次上限、位置/轴角各1e-4、限位及反向轴处理。没有向baseline偷加线搜索或随机重启。alpha>1、负步长现已拒绝；耗尽迭代后仅刷新诊断误差，仍返回失败。

MuJoCo替代Pinocchio、控制点从源 `ee_link` 改为固定抓取变换后的单元开口 `planning_tcp`，均为明确适配。抓取不是上游TCP标定，见 [GRASP_PROVENANCE.md](../reference/planning_upstream/GRASP_PROVENANCE.md)；固定夹爪角、TCP和凸分解几何须随最终manifest冻结。

当前Scenario默认装配系到原机器人base的平移为 **(.30,.20,-.25) m**，绕Z旋转π，共同ready起始七关节为 **(-.62770373654521094, 2.3297993305507192, 1.0289871622237392, 1.2715734368717495, -1.747192543846495, -.81681197466957878, 1.9772845777886507)**。该姿态由development选定，约位于nominal E前60 mm；本次规划从已携带单元的ready姿态开始，不包含原home到ready或获取能量单元过程。原URDF不改；这是机器人base高于装配地面250 mm的本地安装假设。所有正例方法共享安装，不可达负例另有显式更远位置。

`make_task()` 已含完整流程：当前开口→E+0.04e预插入点→E→插入100 mm→升降100 mm→P上翻90°→Q到目标→驻留。P/Q链为外层局部X的Q、内层局部-Y的P；Q不是上翻单元自转。首失败立即返回失败前缀，未把前缀计为完整成功。

## 验证契约及已修复项

- 几何前完整预扫有限性、phase枚举、六阶段覆盖、顺序、起点、零起始且严格递增的时间戳、机构行程及阶段前置约束。NaN与非法枚举不会先进入索引或分段数换算。
- 非approach导出目标必须与机构状态目标一致；全部采样重新做实际FK，要求位置≤.5 mm、轴角≤.002 rad。错误CSV目标不能绕过检查。
- 规则观测已从直接复制计划机构状态改为实际FK反解：基于开口及轴方向求 `P=atan2(hypot(ay,az),ax)`、`Q=atan2(-ay,az)`，再反变换开口求插入/升降。在本机构范围及phase门控下公式正确。Approach显式记为尚未进入机构的零状态。
- 实际观测送入 `AssemblyRules`，插入、升降、P、Q驻留与最后confirm均须成功。规则线性3 mm、P2°、Q5°与.4 s驻留仍为既有模型容差，不是硬件实测精度。
- 时间化为节点零速度的cubic Hermite；解析峰值为 `1.5 max|Δq|/dt` 和 `6 max|Δq|/dt²`。默认mock上限1 rad/s与2 rad/s²，驻留段.5 s；验证重新算峰值，没有用平均差商代替峰值。

所以“三级完成”是理想刚性抓取的运动学轨迹、离散碰撞与规则状态机同时通过，不包含真实夹紧、施力、跟踪控制、RFID或裁判硬件执行。

## 碰撞与采样边界

碰撞按显式geom配对检查，mask为零不代表不检查。非相邻臂刚体、臂/携带物与核心/场景均在检查对象内；同刚体、相邻刚体和安装连接有豁免。空心代理保留孔柱检查，没有整体单元—柱豁免。

指定座合对现允许从正间距连续接近零，最终座合才允许.1 mm数值穿透；原接触前.2–1 mm区间与1 mm自由空间间隙冲突已修复。指定夹爪 `_grip` 分块的许可已不再依赖可能未填充的零距离closest-point witness。加载时检查jaw与unit属于同一weld刚体，完整jaw网格顶点的单元轴向坐标落在[.0348,.1102] m，且YZ投影凸包不含原点、到原点最小距离≥.0320 m。该检查覆盖整个凸代理，刚性变换下不随机械臂姿态改变；运行时仍检查许可配对距离/穿深，不是整体arm-unit豁免。

装配端面证书只用于列明的iron-peg与flange-mount配对。设单位装配轴为n，计算完整unit最小投影减station最大投影；mesh枚举其变换后的全部顶点，cylinder使用精确支持函数 `r*sqrt(nx²+ny²)+h*abs(nz)`。gap≥0证明存在分离面；gap≥-.0001证明沿n平移至多.1 mm即可分离，因而给出允许穿透的保守上界。若不满足则拒绝，不用native CCD的近共面虚假大负距离决定这些端面。孔壁及未命名配对仍走普通距离检查。此证书适用于整个凸体，不依赖单个接触点；返回的gap是轴向分离下界/去穿透上界，不应称为精确欧氏最近距离。

上述逻辑数学与限定配对审查通过；网格凸分解、shell填实AABB、名义柱代理仍不是精细CAD连续接触证书。

在线每段现采用：

```text
n = max(min_substeps, ceil(1.5 * max|Δq| / .008))
u = k/n
q(u) = q0 + (3u²-2u³)(q1-q0)
```

1.5来自cubic导数上界，使相邻采样每关节位移≤.008 rad。它仍不能推出所有几何表面位移≤.5 mm，也不是连续扫掠证明；薄障碍或样本间短时碰撞仍属于离散检查边界。

CLI的 `dense_recheck` 使用同一C++ validator，将joint step减半、最小子步数加倍，属于更密的同算法复查。独立Python审计使用原始URDF+NumPy、XML固定抓取变换、单独机构矩阵链，每段采 **2×在线n**，包含全部在线样本；独立验证位姿、阶段、峰值及驻留，不独立计算网格碰撞。

`plan()` 在configure之后立即调用front-plane检查，故主路径确实检查初始核心状态。函数自身读取当前data，不自动恢复初始机构；单独调用者需注意。此门禁也不证明整个P/Q运动中所有核心构件不越前平面。

## 计时、atlas与统计

`planning_seconds` 从configure前开始，包含配置、初始门禁、任务采样、atlas在线查找、IK/细分、时间化和在线验证。模型加载、atlas离线建库另列。Sparse细分已有逐interval deadline；最终验证及plan成功出口现有后置deadline检查，最后一次碰撞跨deadline不会仍被报为成功。停止仍为协作式检查，返回可略超预算；CSV保留实测秒数。

Atlas只由development上的FullStep完整成功轨迹建库，confirmation与negative不入库；在线记录atlas_source，对新目标仍IK修正并走统一验证。空库现在显式失败，不静默以别的方法冒充atlas。Development评测可能用同场景离线模板，是训练内成绩；confirmation是固定确认任务集，不能夸大为从未接触过的统计holdout。

CLI记录所有方法/场景/重复的成功、失败、时间、计数器和轨迹，异常也保留失败与耗时。Dense复查在主规划计时外单列，其失败会使最终success为假。汇总区分positive、development、confirmation、negative，负例拒绝率不混为正例成功率。完整规划加速只能来自同场景/重复且双方成功的配对；all-run的快速失败不构成加速证据。全量run count、重复检查及原始记录仍需实际独立audit验收。

## 碰撞缓存组合方案审查

`rigid_cache` 使用 Predictor IK。仅 `body_weldid` 相同的几何对缓存距离或已证明的 cutoff 下界；相对位姿固定，所以随臂运动复用有效。缓存以 cutoff 为键，每次 configure 清空，首次求值计入请求。平面剔除条件 `n·(centre-plane_origin)-abs(n)·extent > cutoff` 对包含完整物体的世界 AABB 是保守下界。装配轴支持值仅在同一 collision state 内复用，每个新状态清空；核心与单元相对运动不被跨状态缓存。额外密采样在 configure 后禁用缓存。公开 model/data 仅供观测；请求中修改几何不在此缓存的不可变模型契约内。
