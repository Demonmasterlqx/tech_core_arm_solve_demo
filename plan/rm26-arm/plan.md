# RM26 机械臂接入 MuJoCo

用户范围：使用指定 HKUST RM26 version3 模型，固定机械臂底座，忽略底盘；提供关节位置/速度接口，mock 底层力矩驱动；键盘控制末端前后左右。沿用本项目 C++17 / MuJoCo 3.3.7 / GLFW 技术栈。

1. 固定上游 commit，下载机械臂所需 URDF / 网格，保留关节变换、轴和限位，生成独立 MJCF 场景及来源清单。
2. 新增可调用 ArmSimulation；直接更新受速度和位置限制的关节状态，用 MuJoCo FK/Jacobian 支持末端平移。mock 不提供力矩响应、碰撞阻挡或自由抓取。
3. 新增 `rm26_arm` 可执行程序、GLFW 键盘窗口、CPU 无窗口位置/速度控制、CSV 和截图。WASD/方向键使用底座固定世界坐标，Q/E 升降。
4. 验证源 URDF 与 MJCF FK、七关节位置/速度及限位、末端六方向、无图形构建、现有测试、软件渲染截图和实际键盘事件。
5. 分支 `codex/rm26-arm-mujoco` 仅提交本任务新增内容和必要构建/文档接线；保留工作区已有修改，不推送。

资源：模型下载约十余 MB；物理/运动学使用 CPU；截图使用 Xvfb + Mesa llvmpipe，显式禁用 CUDA 和硬件 OpenGL。测试均有限运行，日志/CSV/截图存 `artifacts/rm26_arm/`，临时显示服务和授权文件结束时清理。现有模型、证据、构建及用户数据不删除。
