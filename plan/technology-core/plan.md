# 科技核心 MuJoCo / C++ 仿真

依据 `reference/RoboMaster_2026_机甲大师超级对抗赛比赛规则手册V2.2.0（20260807）.pdf`，从空目录建立可构建、可交互、可复现实验的科技核心机构仿真。

## 实施范围

1. 核对第 64、79–90 印刷页的能量单元几何、科技核心坐标、P/Q 轴、难度与判定规则，记录来源和假设。
2. C++17 + MuJoCo 3.3.7：科技核心的升降、P 轴翻转、Q 轴侧转、能量单元插入；支持任意规则内装配位姿及双核心。
3. C++ 独立规则判定库；一级到四级流程、连续保持、撤出失败、确认节流、交互卡和同步时限。
4. 提供 GLFW 交互窗口、无窗口演示、CSV 轨迹、图片导出和 CTest 回归验证。
5. 本地 Git 管理，按已完成范围提交；不自动推送。依赖、构建文件和临时图片不入库。

## 边界

- 没有提供工程机器人机械臂/夹爪 CAD、关节定义或驱动参数。本项目仿真科技核心与已对准的能量单元，虚拟夹持器通过广义力操作单元。自由抓取、机器人逆运动学与整场比赛裁判系统不在本次实现内。
- 官方未公开的内部结构、惯量、阻尼、几何细节、检测位置阈值使用显式仿真假设。规则尺寸不等于赛场实物标定。
- 物理在 CPU 上运行；本机截图使用 Xvfb + Mesa llvmpipe 软件渲染，禁止隐式占用 GPU。验证后清理临时显示进程/文件。
- 各命令有限运行；每次实验写入独立输出路径，无后台无限日志。

## 验收

- 从新构建目录完成编译与 CTest。
- 一级、二级、三级及双核心四级的实际 MuJoCo 关节轨迹通过判定，导出可检查数据。
- 测试提前插入、角度离开窗口、确认冷却、步骤先后、四级超时/不同步等失败路径。
- 实際渲染并检查截图；记录依赖版本、验证命令、结果及适用边界。

## 完成记录

以上实施范围已完成。10 个 CTest 项目通过，规则测试含 13 组边界场景；四个等级实际动力学演示、无图形构建、软件截图与有限时长窗口循环均已执行。实际轨迹与资源清理证据见 `docs/validation.md`；约束仿真及未覆盖的机械臂/比赛功能见 `README.md`。
