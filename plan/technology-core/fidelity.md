# 1:1 科技核心模型与视觉标识

## 目标

按用户要求，将现有示意外壳/机构替换为可核验的 1:1 科技核心模型，包含能量单元、可见结构、视觉标识及各装配状态。运行栈保持 MuJoCo + C++，Git 继续由本项目管理。

## 验收证据

- 寻找并记录官方 CAD/三维模型的发布者、版本、原始文件及校验值；同版本实物尺寸或测量资料可补充验证。
- 将原始几何拆分为固定核心、升降/翻转/旋转机构及能量单元，保持毫米到米比例；保留可见凹孔、边缘、紧固件和遮挡关系。
- 保留并核对 MARK 图案、灯条/灯块的尺寸、位置、数量、颜色及官方灯效；不能用抽象矩形替代可见标识。
- 与规则图/官方模型逐视角对照，量测整体尺寸、关键基准与刚体坐标；检查 P/Q 动作中的外形和标识归属。
- 用实际 MuJoCo 渲染、几何检查和装配运行共同验证。规则测试通过不能代替外观与几何一致性证明。

## 当前工作

3. 更新物理模型与渲染、增加可复查的几何/视觉对照材料、运行相关回归并提交。

资源：仍采用 CPU 物理与 Mesa 软件渲染；构建/临时转换在 `build/fidelity-research` 下，最终模型源与来源记录入库。保留用户 PDF 与实验结果，临时派生文件在验证后清理。
